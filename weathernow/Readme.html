Documentation: Weather Now

Dual-Platform Reporting Solution (TRMNL & Responsive Standalone)

Project Overview

Weather Now is a minimalist weather reporting system designed for high-contrast displays. It originated as a custom firmware implementation for TRMNL and was subsequently adapted into a Responsive Standalone application for macOS desktop widgets, Kindle browsers, and mobile devices.

1. Implementation Path A: TRMNL (Liquid)

The TRMNL version is designed for server-side execution, handling manual time offsets for UK BST/GMT.

A. Configuration

  • Timezone Logic: Uses a manual offset block to identify the last Sunday of March and October, adjusting hr_now to account for daylight savings.[cite: 1]
  • Coordinates: Hardcoded to Castleton of Eassie (56.6071, -3.0858).[cite: 1]

2. Implementation Path B: Standalone (Responsive HTML/JS)

The Standalone version uses a reflow architecture to support both fixed-canvas desktop viewing and fluid mobile viewing.

A. Desktop View

  • Fixed Dimensions: Locked at 840x480.
  • Visuals: Includes the flourish swoosh and custom quote.
  • Layout: Three-column header with side-by-side Location, Temperature, and Wind/Rain stats.

B. Mobile/Kindle Reflow

  • Symmetrical Grid: Uses a 2 x 3 grid for hourly data. The "Later" block is reformatted from a summary into a 5-line stack to maintain grid symmetry.
  • Side-by-Side Hero: Temperature and weather conditions are paired with Rain and Wind stats in a two-column hero section for density.
  • Emoji Suppression: Uses ︎ to force sun glyphs to render as black text instead of yellow emojis.

3. Shared Core Logic

A. The "Blindfold" Methodology

To avoid redundant data, secondary scans (Later and Overnight) ignore the immediate 5-hour window, beginning strictly at hr_now + 6.[cite: 1]

B. "Tomorrow" Vibe Track

Analyzes the daylight window (Sunrise to Sunset). If the precipitation probability is ≥ 40% for at least 3 hours, the day is classified as "Rainy" regardless of cloud cover.[cite: 1]
